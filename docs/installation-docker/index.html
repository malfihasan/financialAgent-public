Install with Docker¶

The Docker release contains the packaged FinAgent binary, dashboard, documentation, Node.js runtime, and Ollama. It does not publish the private source tree or raw Python source files.

Requirements¶

  • Docker Desktop, or Docker Engine with Docker Compose.
  • FinAgent-Docker-x86_64.tar.gz from the latest release.
  • docker_up.sh and docker-compose.yml from the public repository.
  • One host folder for statements and one for processing output.

Load and start¶

Keep the three downloaded files in one folder, then run:

docker load -i FinAgent-Docker-x86_64.tar.gz
chmod +x docker_up.sh

./docker_up.sh \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing" \
  --no-ollama-model

Open the dashboard at http://localhost:3001 and the local documentation at http://localhost:3003. Missing host folders are created automatically. Their paths appear locked in Settings because changing a bind mount requires recreating the container.

Preview first

Add --dry-run to print the Compose command, ports, mounts, provider, and model choice without starting a container.

Ports¶

The dashboard defaults to host port 3001; documentation defaults to the dashboard port plus 2. Set either explicitly:

./docker_up.sh \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing" \
  --port 4100 \
  --docs-port 4200 \
  --no-ollama-model

Ports must be different whole numbers from 1024 through 65535. Keep the dashboard port at 65533 or lower because FinAgent reserves adjacent internal ports.

Ollama models¶

Ollama is installed in the image. Downloads are optional and persist in the ollama-data volume.

# Pull and select qwen2.5:0.5b
./docker_up.sh --ollama-model \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing"

# Pull and select another model
./docker_up.sh --ollama-model qwen2.5:3b \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing"

With neither model flag, an interactive launch asks whether to download the small default. An unattended launch does not prompt. Use --no-ollama-model to skip downloading explicitly.

Claude and OpenRouter¶

Keep cloud keys out of shell history by using a local permission-restricted environment file.

mkdir -p "$HOME/.config/finagent"
printf '%s\n' 'ANTHROPIC_API_KEY=your-key' > "$HOME/.config/finagent/docker.env"
chmod 600 "$HOME/.config/finagent/docker.env"

./docker_up.sh --llm-provider claude \
  --env-file "$HOME/.config/finagent/docker.env" \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing"

mkdir -p "$HOME/.config/finagent"
printf '%s\n' 'OPENROUTER_API_KEY=your-key' > "$HOME/.config/finagent/docker.env"
chmod 600 "$HOME/.config/finagent/docker.env"

./docker_up.sh --llm-provider open_router \
  --env-file "$HOME/.config/finagent/docker.env" \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing"

The env file accepts ANTHROPIC_API_KEY and OPENROUTER_API_KEY. Keys are injected at startup, masked in the dashboard, and never copied into the image.

Persistent data¶

Data Storage Survives recreation
Imported statements Host --statements folder Yes
Processing and dashboard data Host --processing folder Yes
FinAgent settings Host --config folder, default .docker-config Yes
Ollama models Docker volume ollama-data Yes

After setup, use Import and Process exactly as in a native installation.

Check, restart, and stop¶

docker ps --filter name=finagent
docker logs finagent
curl http://localhost:3001/api/health

docker restart finagent
docker compose --project-name finagent down

Run ./docker_up.sh again to recreate a stopped container with the mounts, ports, and provider options you want.

Update¶

  1. Download the new image archive and current launcher files.
  2. Run docker compose --project-name finagent down.
  3. Run docker load -i FinAgent-Docker-x86_64.tar.gz.
  4. Start again with your normal ./docker_up.sh options.

Mounted data, configuration, and Ollama models remain available.

Troubleshooting¶

  • Invalid port: choose distinct values in the documented range.
  • Cloud key missing: provide the key with --env-file or save it in Settings.
  • Ollama model unavailable: restart with --ollama-model or --ollama-model <name>.
  • Image not loaded: run docker load -i FinAgent-Docker-x86_64.tar.gz.
  • All Docker launcher options: run ./docker_up.sh --help.
