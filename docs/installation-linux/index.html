Install on Linux¶

The Linux x86_64 archive contains the packaged FinAgent binary and dashboard runtime. Normal use does not require a separate Python or Node.js installation.

Download and install¶

  1. Download FinAgent-Linux-x86_64.tar.gz.

  2. Extract the archive:

    tar -xzf FinAgent-Linux-x86_64.tar.gz
cd finagent_bundle

  3. Run the included installer. It installs to your user account, adds the finagent command, and creates an application-menu entry without sudo:

    ./install.sh

  4. Start FinAgent from the app menu or terminal:

    finagent

To run the bundle in place instead, mark the executable if needed and launch it directly:

chmod +x ./finagent
./finagent

Desktop integration notes¶

A browser must be available for the dashboard. On minimal or remote Linux systems, start FinAgent and open the printed http://localhost:<port> address from a browser that can reach the same machine.

Next steps¶

The first launch opens Settings. Complete it, Import a bank CSV or supported tabular text statement, then use Process. For automation and maintenance options, see Running from the Terminal.
