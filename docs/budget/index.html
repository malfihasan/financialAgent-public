Budget¶

In FinAgent: Primary navigation -> Budget

Budget compares a monthly plan with transaction history. It separates income, Fixed / Recurring costs, variable costs, yearly costs, savings strategies, and Wishlist / Piggy Bank goals.

Create and archive a budget¶

Start with the sample budget, choose its effective month, and export it before saving persistent edits. FinAgent stores the current plan as local CSV files in the budget folder. Archiving creates a month-specific copy; replacing an existing archive requires explicit approval.

Map expense entries to transaction categories so Budget can calculate actual spending. Actuals include transaction split allocations, so a mixed purchase can contribute to several mapped categories without changing the authoritative transaction row.

Fixed / Recurring¶

Use Fixed / Recurring for expected monthly commitments such as rent, utilities, insurance, and subscriptions. Existing CSV data continues to use the internal fixed category; the dashboard label is clearer without changing the file format.

Wishlist / Piggy Bank¶

Wishlist goals reserve part of the monthly plan for a future purchase or milestone. Each goal requires:

  • A unique name.
  • A goal amount greater than zero.
  • A monthly allocation greater than zero.
  • A valid start date and target date, with the target on or after the start.

The monthly allocation is included in planned expenses and reduces budgeted net savings. Goals are stored in budget_wishlist.csv and remain part of each archived budget.

Create, edit, or delete goals in the Wishlist group of the Budget vs Actual table, immediately after Income and Other Debits. Each row uses Wishlist for its Type and Group, displays its monthly allocation under Budget, leaves spent columns empty, and shows accumulated planned contributions under Balance. Total Wishlist Expense summarizes the monthly allocation and planned balance for all goals. Wishlist allocations remain included in the table's Net (Income - Expenses) calculation.

Selecting Add Wishlist opens the new-goal row and moves it into view. Once you enter a goal amount, start date, and target date, the editor previews the monthly budget needed to reach the goal. This estimate counts both the start and target months and does not replace the monthly allocation you choose.

Progress meaning¶

Wishlist progress is planned contribution progress, not a bank-balance or transfer tracker. For the budget's effective month, FinAgent multiplies the monthly allocation by the number of months from the start month through the effective month, inclusive. Progress is zero before the start month.

The read-only Wishlist / Piggy Bank Details card below Net Summary shows goal totals, dates, planned saved, remaining amount, target-date pacing, and any amount planned above the goal. A goal is fulfilled when planned contributions reach its goal amount. Saving a goal does not create or modify a transaction.

Keep actual purchases accurate

When one purchase funds more than one purpose, split it on Transactions. Use Wishlist for the plan leading up to a purchase, not to recategorize the purchase itself.
