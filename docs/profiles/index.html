Profiles: Personal & Dev¶

The dashboard has a profile toggle (top-right of the Settings page) with two modes. Personal is the default and what almost everyone should use.

Personal (default)¶

Personal keeps the dashboard focused and privacy-first:

  • Location lookup offers Open Street Map (free, built in) or off.
  • An optional checkbox lets you share a contact email with OpenStreetMap — purely voluntary feedback, off by default.
  • Advanced/experimental lookup integrations are hidden.
  • Category editing is limited to what the pipeline supports safely.

Dev¶

Dev mode unlocks maintainer features:

  • A separate development configuration that stays isolated from your personal data.
  • The Add category button on the Categories page (still discouraged — the category set is tuned for the rule engine and LLM prompts).

Activating Dev¶

Flip the toggle to Dev on the Settings page and enter the password (finagent). The choice is stored in your config as ui_profile and persists across restarts. Switch back to Personal at any time — no password needed.

Terminal config profiles¶

From the terminal, keep to the same two supported profiles used by the dashboard:

finagent --profile personal
finagent --profile dev

Each profile keeps its own folders, provider, and settings. See Running from the terminal.
