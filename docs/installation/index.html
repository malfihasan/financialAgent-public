Installation¶

FinAgent ships as a standalone binary — no Python required for normal use. Pick your platform below.

macOS quick start¶

  1. Download the latest FinAgent-<version>-macOS.dmg from the GitHub releases page.
  2. Install: open the DMG and drag FinAgent.app into Applications.

  3. First launch — approve the security check. The app is not distributed through the App Store, so macOS Gatekeeper blocks a normal double-click the first time:

    • Right-click (or Control-click) FinAgent.app → Open → Open.
    • If macOS still refuses ("Apple could not verify…"), go to System Settings → Privacy & Security, scroll to the Security section, and click "Open Anyway" next to the FinAgent message, then confirm with your password or Touch ID.

    • Terminal alternative (removes the quarantine flag in one step):

      xattr -dr com.apple.quarantine /Applications/FinAgent.app

    This approval is needed once per install/update. 4. Launch. Double-clicking FinAgent.app opens a Terminal window, starts the app, and opens your browser on the dashboard. First run walks you through setup.

Set up the finagent terminal alias (macOS)¶

The docs and dashboard refer to the finagent command. The binary lives inside the app bundle, so add an alias to your shell profile:

# zsh (default on modern macOS)
echo 'alias finagent="/Applications/FinAgent.app/Contents/MacOS/finagent"' >> ~/.zshrc
source ~/.zshrc

# bash
echo 'alias finagent="/Applications/FinAgent.app/Contents/MacOS/finagent"' >> ~/.bash_profile
source ~/.bash_profile

Verify it works:

finagent --version

The wrapper at Contents/MacOS/finagent detects how it was invoked: from a shell it runs inline (all terminal flags work as expected); from Finder it opens Terminal.app for you.

Linux quick start¶

  1. Download the Linux archive from the releases page and extract it:

    tar -xzf FinAgent-<version>-linux.tar.gz -C ~/finagent

  2. Make the command available on your PATH (pick one):

    # symlink (recommended)
sudo ln -s ~/finagent/finagent /usr/local/bin/finagent

# or shell alias
echo 'alias finagent="$HOME/finagent/finagent"' >> ~/.bashrc && source ~/.bashrc

  3. Run finagent — the dashboard opens in your default browser. If your distribution blocks the binary, mark it executable first: chmod +x ~/finagent/finagent.

Windows quick start¶

  1. Download the Windows .zip from the releases page and extract it, e.g. to C:\Program Files\FinAgent.
  2. SmartScreen approval (first run only): double-click finagent.exe — when "Windows protected your PC" appears, click More info → Run anyway.

  3. Optional — add FinAgent to your PATH so finagent works in PowerShell: Settings → System → About → Advanced system settings → Environment Variables, edit Path, and add the FinAgent folder. Then:

    finagent --version

Requirements¶

  • A local LLM provider for categorization — Ollama (recommended) or LM Studio — or an OpenRouter API key if you accept a cloud provider.
  • ~500 MB disk for the app plus space for your processed data.
