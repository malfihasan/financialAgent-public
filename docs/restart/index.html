Restarting FinAgent¶

Related setting: Configuration Settings Dashboard

Restart FinAgent after changing the dashboard port or when a local service must be started with a new environment. Model and location selections usually need a new Process run, not an application restart.

macOS app or native binary¶

  1. Stop FinAgent by pressing ++ctrl+c++ in the Terminal window it opened, or close that window. On macOS, you can also quit FinAgent from the Dock.
  2. Open FinAgent again from Applications, the Start Menu, desktop shortcut, or your platform's normal launcher.
  3. Use the new dashboard address if you changed the port.

A normal relaunch opens the existing dashboard data without automatically processing statements.

Terminal¶

Stop the active process with ++ctrl+c++, then run:

finagent

To state the dashboard-only behavior explicitly:

finagent --dashboard-only

Use finagent --profile dev when the Dev profile should be active at startup. See Running from the Terminal for every option.

Docker¶

Restart the current container without changing mounts or settings:

docker restart finagent

To change ports, mounted folders, startup provider, or model, recreate it:

docker compose --project-name finagent down
./docker_up.sh \
  --statements "$HOME/Documents/FinAgent/statements" \
  --processing "$HOME/Documents/FinAgent/processing" \
  --no-ollama-model

Statements, processing output, configuration, and downloaded Ollama models remain in their host folders or named volume. See Docker Installation for all startup options.

Troubleshooting¶

Port already in use¶

An earlier process may still own the configured port. On macOS or Linux:

lsof -i tcp:3001
kill <PID>

Replace 3001 with the configured dashboard port and stop only the process you recognize as the old FinAgent instance.

Dashboard looks stale¶

Wait for Process to report completion, then hard-refresh the browser (++cmd+shift+r++ on macOS or ++ctrl+shift+r++ on Windows/Linux). A normal restart does not rerun processing.

Folder paths need to change¶

Native folder paths are locked after initial setup. Stop FinAgent and run:

finagent --reconfigure

For Docker, recreate the container with new --statements and --processing mounts instead.
