First-run setup¶

The very first time you launch FinAgent (no ~/.finagent/config.json yet), the app starts the dashboard and opens the Settings page in setup mode. Every other page stays locked until setup is complete.

The three steps¶

  1. Folders — choose where your raw statements live and where processed data should go. FinAgent creates the bank subfolders (AMEX, BOA, CHASE, CITI, USBANK — each with CheckingAC and CreditAC) automatically when you complete setup.
  2. Categorization engine — pick an LLM provider (Ollama, LM Studio, or OpenRouter) and a location-lookup method.
  3. Dashboard — pick the port the dashboard runs on.

Press Complete setup. The Import page unlocks immediately; the remaining pages unlock after your first processing run generates dashboard data.

How pages unlock¶

State Unlocked pages
No config yet Settings only
Setup complete, no statements Settings, Import
Statements imported, no dashboard data Settings, Import, Process
Dashboard data exists Everything

Prefer the terminal?¶

The classic terminal wizard is still there:

finagent --setup

See Running from the terminal for all flags.
