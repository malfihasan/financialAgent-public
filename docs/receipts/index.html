Receipts (item-level breakdown)¶

In FinAgent: Import Receipts

Receipts let FinAgent split one bank transaction — for example a single Walmart charge — into the individual items you bought, each with its own category. The dashboard (Overview, Monthly, Budget, Categories, Transactions) then shows your spending by what you actually bought, not just by store.

Supported stores

Walmart (in-store receipts and walmart.com order pages saved as PDF). Amazon is listed on the Import page as coming soon.

1. Import receipts¶

  1. Open Import and scroll to Receipts, then choose Walmart.
  2. Pick one or many receipt PDFs. Duplicates (the exact same file) are skipped and listed so you know nothing was added twice.
  3. Select Import. Files are filed in your statements folder under WALMART/ and renamed walmart_<import date>_<number>.pdf.

The date in the file name is the day you imported the receipt — not the day you shopped. The real purchase date is read from the receipt itself during processing. The number always increases and is never reused, even after you delete a receipt.

2. Run¶

Select Run receipts in the receipt list (or Run processing; receipts are included automatically whenever any are imported). The run does this, in order:

  1. Bank statements are processed as usual (when you also imported statements).
  2. Reading — each PDF is read with a local OCR engine. The result is cached, so a receipt is only ever read once. The purchase date must be found; if not, the receipt is reported as unreadable.
  3. Matching — the receipt is linked to the bank transaction with the same amount whose date is within ±2 days of the purchase date. A bank description that looks like the store (WAL-MART, WALMART.COM…) is preferred but not required.
  4. Categorizing — every item gets a category. Certain rules run first (for example Walmart marks food items with an F), then the language model handles what is left. Results are kept; later runs only categorize new items.
  5. Item amounts (including each item's share of tax and discounts) always add up to the bank amount exactly.

Tick Re-categorize items that were already categorized (here, or in the Merge guard on Process) to re-run rules and the model on existing items. Categories you changed yourself are kept unless you also choose to overwrite your dashboard edits.

3. See and correct the result¶

On Transactions, a transaction with a receipt shows an arrow. Expand it to see every item with its category; use the pencil on an item to change its category (saved as user defined). All other pages use the item categories in place of the single bank-line category.

When something goes wrong¶

Every receipt on the Import page shows a status — Linked, No transaction yet, Needs attention or Ready to process — and any problems stay listed there until fixed:

Message What to do
No purchase date / SUBTOTAL / TOTAL could be read Save the receipt again as a clear PDF and import it, or delete it.
No items could be read Make sure the PDF is the receipt itself and not a blank or cropped page.
OCR engine not available Reinstall FinAgent (or install the OCR components when running from source), then run again.
Items do not add up to the SUBTOTAL/TOTAL Compare the item list with your receipt; a line may be missing or misread.
No matching bank transaction Import the bank statement that contains the purchase, then run again.
Several transactions fit Import the statement of the card you paid with.

In the Dev profile an unmatched receipt also offers Add as a new transaction — enter the bank, account type and last 4 digits and FinAgent creates the missing transaction and links it.

Deleting a receipt¶

Select the trash icon on the receipt (or delete the PDF from the WALMART folder). Its item breakdown and link are removed on the spot or at the next run, and the transaction goes back to a single line.

Files¶

File Where Purpose
walmart_<date>_<n>.pdf <statements>/WALMART/ Your imported receipts
receipts_master.csv dashboard data folder One row per receipt: status, totals, linked transaction, problems
receipt_items_master.csv dashboard data folder One row per item with its category
master_transactions.csv dashboard data folder Gains receipt_available (yes/no) and receipt_id columns

Terminal¶

finagent --pipeline-only --yes                  # banks, then receipts if any were imported
finagent --pipeline-only --yes --receipts-only  # receipts only
finagent --pipeline-only --yes --no-receipts    # banks only
finagent ... --overwrite-receipts               # re-categorize receipt items
finagent --delete-receipt --receipt-id walmart_20261006_0001
