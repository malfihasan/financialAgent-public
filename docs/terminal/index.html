Running from the terminal¶

Everything the dashboard does — and more — is available from the terminal. Use the finagent command after installation.

Everyday commands¶

finagent                    # open the dashboard (default)
finagent --terminal         # open the interactive terminal menu
finagent --dashboard-only   # skip processing, just serve the dashboard
finagent --pipeline-only    # process data, don't start the dashboard
finagent --setup            # (re)run the interactive setup wizard
finagent --version          # print the version
finagent --help             # full flag reference

Running finagent without a switch now opens the dashboard directly and does not start processing or show the terminal menu. Use finagent --terminal when you want the numbered terminal options. Processing still runs when you pass a pipeline switch such as --orgs, or when you start it from the dashboard's Process page.

Pipeline switches¶

finagent --orgs boa,amex            # only these banks
finagent --month 2026-05            # single month
finagent --start-date 2026-01-01 --end-date 2026-06-30
finagent --clean-data               # wipe generated temp data first
finagent --no-location-lookup       # rules + LLM only
finagent --lookup-method nominatim  # one-run lookup override
finagent --clear-lookup-cache       # wipe the lookup cache
finagent --refresh-lookup-cache     # re-resolve every location

If no statements are present, a terminal processing command starts the dashboard and opens its Import page instead of running the pipeline. Import a CSV or supported tabular text bank export there; PDF statements are not supported. The old desktop import window is no longer used.

Cloud API keys from the terminal

Keys entered in FinAgent Settings or finagent --setup are saved in your profile, so you do not need to export them again. If you select a cloud provider only with terminal options and have not saved its key, set the matching environment variable before starting FinAgent. The pipeline and the dashboard server inherit it.

export OPENROUTER_API_KEY="sk-or-your-key"
finagent --llm-provider open_router --orgs boa

export ANTHROPIC_API_KEY="sk-ant-your-key"
finagent --llm-provider claude --orgs boa

$env:OPENROUTER_API_KEY = "sk-or-your-key"
finagent --llm-provider open_router --orgs boa

$env:ANTHROPIC_API_KEY = "sk-ant-your-key"
finagent --llm-provider claude --orgs boa

These commands set the key only for the current terminal session. Avoid putting API keys directly in commands that may be saved in shell history.

Maintenance¶

finagent --overwrite-dashboard-data   # regenerate dashboard data from scratch
finagent --delete-dashboard-data      # remove dashboard data (asks first)
finagent --reset-all                  # factory reset config + data (asks first)
finagent --reset-all --with-statements  # ...including raw statements
finagent --yes                        # answer "yes" to confirmation prompts

Profiles from the terminal¶

finagent --profile personal   # run with the personal profile
finagent --profile dev        # run with the dev profile

Only these two profiles are supported in the user-facing workflow right now. See Profiles for what the dashboard's Personal/Dev toggle does.

Dashboard view range¶

finagent --dashboard-only --start-date 2026-01-01 --end-date 2026-03-31

Serves the dashboard restricted to that date window without reprocessing.
