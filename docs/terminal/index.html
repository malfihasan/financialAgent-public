Running from the Terminal¶

Open your system terminal, then run finagent --terminal.

The packaged finagent command can open the dashboard, run processing without the browser, select a profile, and perform maintenance. On macOS, create the alias described in Install on macOS first.

Launch and setup¶

Command Behavior
finagent Open the dashboard using the Personal profile.
finagent --terminal Open the numbered interactive terminal menu.
finagent --dashboard-only Start the dashboard without processing.
finagent --pipeline-only Process and update dashboard data without starting another dashboard server.
finagent --calculation-only Process without starting the dashboard.
finagent --no-dashboard Alias for --calculation-only.
finagent --setup Run the interactive setup wizard, then optionally open Import.
finagent --reconfigure Alias for --setup.
finagent --version Print the installed version.
finagent --help or -h Print pipeline argument help.

With no arguments, FinAgent opens the existing dashboard and does not reprocess. The Process page starts normal dashboard runs.

Select a profile¶

--profile may precede any launch, processing, or maintenance command:

finagent --profile personal
finagent --profile dev
finagent --profile dev --orgs boa
finagent --profile=dev --dashboard-only

Personal and Dev are the supported user-facing profiles. See Profiles for isolation and activation behavior.

Pipeline filters¶

Option Example Purpose
--orgs --orgs boa,amex,chase Process only comma-separated institution IDs.
--month --month 2026-05 Process one calendar month.
--start-date --start-date 2026-01-01 Inclusive start date; YYYYMMDD also works.
--end-date --end-date 2026-06-30 Inclusive end date; YYYYMMDD also works.
--clean-data --clean-data Delete generated temp and transaction output before the run.

Examples:

finagent --orgs boa,amex
finagent --month 2026-05
finagent --start-date 2026-01-01 --end-date 2026-06-30
finagent --clean-data --orgs boa

When processing also updates the dashboard, a selected date range becomes the inclusive dashboard view without deleting older rows from the persistent master.

Location Engine options¶

Option Purpose
--no-location-lookup Skip location categorization for this run.
--lookup-method nominatim Override the run with OpenStreetMap.
--lookup-method google_maps Override with Dev Selenium lookup.
--lookup-method combined Try OpenStreetMap, then Dev Selenium lookup.
--lookup-method place_api Override with Google Places API lookup.
--lookup-method place_api_combined Try OpenStreetMap, then Google Places API.
--clear-lookup-cache Delete the active method's cache before processing.
--refresh-lookup-cache Ignore cached values and replace them with fresh lookups.

See Location Engine before selecting a method that uses an external service.

Model options¶

Option Purpose
--llm-provider ollama Use the local Ollama provider for this run.
--llm-provider open_router Use the configured OpenRouter model and key.
--llm-provider claude Use the configured Claude model and key.
--no-llm Skip model categorization but still write final output.
--llm-batch-size NUMBER Override descriptions sent per model request.
--clear-llm-cache Delete the active model's categorization cache first.
--refresh-llm-cache Rebuild the active model's cache from scratch.

Use --no-llm for a deterministic-only run; none is a saved Settings value, not a valid --llm-provider argument. See AI Engine for provider installation and behavior.

Diagnostic commands¶

finagent --lookup-method place_api \
  --test-location-lookup "COFFEE SHOP BOSTON MA"

finagent --test-open-router --open-router-config-only
finagent --test-open-router

--test-location-lookup DESCRIPTION runs one merchant through the selected resolver and exits. --test-open-router validates configuration and makes one minimal API request; adding --open-router-config-only skips the network call.

Non-interactive merge controls¶

These switches accompany --pipeline-only, which is also how the dashboard server starts a background processing run:

Option Purpose
--overwrite-user-defined Allow new output to replace prior manual categories.
--overwrite-llm Allow new output to replace prior model categories.
--overwrite-location Allow new output to replace prior location categories.

Without an overwrite switch, that category source remains protected during the merge.

finagent --pipeline-only --overwrite-llm --overwrite-location

Cloud API keys¶

Keys saved in Settings or finagent --setup are loaded from the active profile. For a temporary shell-only provider choice, set the matching environment variable before launching.

export OPENROUTER_API_KEY="sk-or-your-key"
finagent --llm-provider open_router --orgs boa

export ANTHROPIC_API_KEY="sk-ant-your-key"
finagent --llm-provider claude --orgs boa

$env:OPENROUTER_API_KEY = "sk-or-your-key"
finagent --llm-provider open_router --orgs boa

$env:ANTHROPIC_API_KEY = "sk-ant-your-key"
finagent --llm-provider claude --orgs boa

Avoid typing secrets directly into commands that shell history may save.

Dashboard data maintenance¶

Command Behavior
finagent --overwrite-dashboard-data Rebuild the dashboard master from the latest pipeline output.
finagent --delete-dashboard-data Delete only the dashboard transaction master after confirmation.
finagent --reset-all Reset configuration and generated data after confirmation.
finagent --reset-all --with-statements Also delete raw statements during the reset.
--yes or -y Accept supported confirmation prompts non-interactively.

These operations are intentionally separate from a normal Process run. Back up local data before a reset.

Dashboard-only date view¶

finagent --dashboard-only \
  --start-date 2026-01-01 \
  --end-date 2026-03-31

This opens a restricted inclusive view without processing or deleting older master transactions.

No statements available¶

A terminal processing request with no statement files opens the dashboard on Import instead of running an empty pipeline. Import a supported CSV or tabular Bank of America checking export, then run the command again.
