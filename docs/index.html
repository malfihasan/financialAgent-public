FinAgent¶

FinAgent is a local-first personal finance agent. It imports your bank and credit-card statements, categorizes every transaction with rules, location lookup, and a local LLM, and renders everything in a dashboard that runs on your own machine.

Nothing leaves your computer. No cloud accounts, no telemetry, no data uploads.

The short version¶

  1. Launch FinAgent. On first run the dashboard opens on the Settings page.
  2. Complete setup — choose your statements and processing folders, pick an LLM provider and a location-lookup method, then press Complete setup.
  3. Import statements on the Import page. Use a CSV or supported tabular text export from your bank — PDF statements are not supported.
  4. Process them on the Process page — a run button with live progress.
  5. Explore the Overview, Monthly, Transactions, and Budget pages.

Start with Quick start, then use Installation for platform details, providers, Docker persistence, updates, and troubleshooting.
